# PostgreSQL E-commerce SQL Analysis Project

## Objective
Analyze e-commerce sales data using PostgreSQL and SQL queries to generate business insights and revenue.

## Technologies Used
- PostgreSQL
- SQL
- VSCode
- pgAdmin

## SQL Skills Demonstrated

- JOINs
- GROUP BY
- Aggregate Functions
- Revenue Analysis
- Data Filtering
- Business Insights

## Database Tables
- customers
- orders
- order_items
- products
- categories

## Analysis Performed
- Monthly Revenue Analysis
- Top Customers by Revenue
- Top Products by Revenue
- Revenue by Category
- Order Revenue Analysis
- Orders by Status
- Customers Without Orders
- Average Order Value
